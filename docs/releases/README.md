# Release notes

One file per repository release, named for its tag: `v0.1.0.md` holds the notes of
`v0.1.0`. The release workflow refuses a tag that has no file here and publishes the file
as the release's notes ([releasing.md](../releasing.md)). Nothing generates them.

A file is added by the pull request that prepares the release and is not edited after
the release is published. A correction is a line in the next release's notes.
