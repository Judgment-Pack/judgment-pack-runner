Runner v0.14.0: a job advances to an explicitly reviewed release through an upgrade endpoint that keeps every existing run's pinned release and records an immutable revision receipt; durable record delivery and offline workspace relocation are preserved for the Desk's local installation.

## What an operator must do

- **Nothing for existing runs.** Exports, the journal, `verify-run`'s report, its exit codes and refusal flags are byte-identical to v0.13.0's for every existing run; the twelve published vectors recompute byte for byte. The store migrates transactionally on start, retaining creation and upgrade receipts.
- **To move a job to a new release**, call the upgrade endpoint with the job's exact current revision: it pauses for pending source occurrences, leaves existing triggers paused under the new revision, and returns the receipt; retrying the same request returns the original receipt after later upgrades or a restart. A published pack identity reused with different content is refused.

## Job upgrades with immutable revision receipts (#92)

- The upgrade endpoint requires the exact current revision; a stale request is refused by name. Pending source occurrences are paused, not replayed; historical runs keep the release they were pinned to.
- Receipts are immutable and replayed on retry across upgrades and restarts; the migration and its rollback, stale requests, every pending occurrence state, historical run pins and receipt replay are covered by tests; a stale-trigger-resume issue the review found was fixed with a regression test.

## Durable record delivery and workspace relocation (#93)

- Release-bound durable record delivery: owner deliveries retain their exact retry identities across downtime and pause; public credential delivery is unchanged; the delivery route uses the shared strict input decoder, with the nested version-3 dialect identity checks and the installation-attributed, coalesced refusal journal. No accepted event or historical run is replayed or rewritten.
- Offline workspace relocation is preserved; the Desk's real-companion suite exercises outbox reconciliation and workspace moves. The review's two findings, a missing raw version-3 decoding and refusal journaling, were corrected with regression coverage.
