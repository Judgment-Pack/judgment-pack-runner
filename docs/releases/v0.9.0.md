## `verify-run` names the instant freshness is judged against (#55)

- **A program that reads `verify-run`'s report** sees one new member, `unsignedFreshness`, on every run with a verified acquisition that was not skipped, copy mappings included; it is absent for an export without lineage. It names `preparation.verifiedAt`, the instant each acquisition's freshness and each computed calculator's table freshness were judged against, and the sources judged. No signature covers that instant: freshness is consistent with the instant the export supplies; nothing establishes that instant was the admission instant. The line on standard error says the same. The exit code and every refusal are unchanged. Committing the instant to signed material needs a Runtime change (runtime #263).
