# Private manual admission wire draft 1

Exact schemas and synthetic (non-executable) vectors are in `jps-policy-manual-admission-wire.json`. `$defs` are closed: exact case-sensitive members, no duplicates, unknown fields, nulls or coercion. All counters are canonical positive uint64 decimal strings. Version is integer literal1. NDJSON frames are valid UTF-8, ≤65,536 bytes including LF, one request in flight, 5seconds/exchange, no retries; cancellation/deadline/EOF/protocol fault permanently closes channel. Reply method/sequence must exactly echo outstanding request; extra/preplayed replies refuse.

`executorAdmission` boot exactly: `{version,fd:3,installationId,machineWorkspace,runnerWorkspace,executorId,challenge,profile:"local-admin-manual-pack/1"}`. Installation/machine/executor/challenge are bare64 lowercase hex; Runner workspace is bounded visibleASCII and exactly matches both boot.workspace and ownership.runnerWorkspace. The host creates BOTH raw socketpair ends atomically close-on-exec (or holds syscall.ForkLock.RLock across creation and setting both flags), passes only the designated child socket via ExtraFiles, and closes originals; otherwise an unrelated original fd can bypass the negotiated slot. Slot3 is the sole authority socket descriptor; Runner marks it close-on-exec, duplicates through net.FileConn, and closes the supplied original before any Runtime invocation. Runtime receives ONLY separately appended ownership descriptor. Require matching executor-ownership/1 and policy-manual-pack-run/1. Historical Phase A refused this profile and reported closed v2/false; the completed supported-host candidate reports closed v3 with the sole governance profile local-admin-manual-pack/1.

Request `{version:1,sequence,method,body}`. Reply `{version:1,sequence,method,status:"ok"|"refused",body}`. A refusal body is only `{code}` from finite fixture enum; it conveys no retry permission or nonmutation guarantee. Method bodies/results follow fixture exactly:

- `activate`: challenge+actual signing mode/public key → delivery committed/recovered, durable epoch, requestDigest. Only original committed activation proceeds. Host retained context supplies workspace/executor identity.
- `inspect`: exact resource tuple → observed registration revision/digest, current eligible/reason/time. Unknown resource refuses. Observation never permits launch.
- `reserve`: intentId+rawRequestDigest+resource+registration+full descriptor payload → committed/recovered operationId/attemptId/epoch/requestDigest. Failed eligibility can durably seal the one-attempt barrier before refusal. One attempt per original intent.
- `commitStart`: complete reserve body+operationId+attemptId+epoch → committed/recovered decision(start-committed/blocked), identities/requestDigest/reason/time/checked authorityRevision. Blocked is durable; only fresh committed+start-committed can later mint a one-use launch object after local persistence.
- `history`: intentId → observed intent/operation/attempt/epoch/state/requestDigest/reason/time. This diagnoses a lost reserve even before the caller knows operationId. Never grants a launch.

Resource tuple: `{jobId,jobRevision,releaseId,releaseProfile:"judgment-pack-runner/canonical/1",releaseDigest}`. Registration `{revision,digest}`. Payload `{profile:"judgment-pack-runner/execution-payload/1",digest,bytes}`; bytes is canonical base64 of exact canonical descriptor≤4KiB, verified against digest/profile and complete trusted intent/registration/signing bindings. RequestDigest hashes canonical `{method,body}`, excluding sequence/version; safe typed string bodies share Runner canonical/1 and Desk safe canonical encoding. authorityRevision is the bare hash of the exact checked precommit Policy ledger (avoids receipt/hash recursion). All other digest fields are sha256:-prefixed.

Owner HTTP export `GET /v1/jobs/{job}/execution-binding`: `{version:1,workspace,jobId,jobRevision,releaseId,releaseProfile,releaseDigest,releaseBytes}`. Exact existing canonical typed Release preimage is base64≤8MiB; profile restrictions and absence of every trigger enforced. New endpoint grants no authority.

`rawRequestDigest` in reserve and commitStart is SHA256 of the exact original manual HTTP body. It is compared against the host-prepared intent, independently of facts/evidence descriptor digests, and is excluded from the stable logical-operation key. Even an outer-whitespace change with the same original Idempotency-Key conflicts.

Private host ingress header `X-Jpack-Manual-Intent` is stripped/rejected at browser proxy; it is forwarded only by Desk after anchored local-admin intent preparation. Runner preserves exact original body bytes and facts/evidence preimages; no body caller/operation fields grant authority. Historical Phase A types/transports were inactive; the completed candidate requires the full registration, reserve and one-use operational gate.
