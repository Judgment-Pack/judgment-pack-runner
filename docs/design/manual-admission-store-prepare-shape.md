Paths are existing clean absolute private real directories with disjoint state/external custody. No secret boot, authority socket, listener, provider, Runtime, recovery or worker.

Request: version1, stable random bare64hex prepareId, dir, Runner workspace, existing owner, leaseFd3, existing executorOwnership v1, executionDemand v1. Demand is exactly version1, installationId, machineWorkspace, runnerWorkspace, executorId, profile local-admin-manual-pack/1. Repeated identities must agree with current state, retained external custody and Desk pending intent. Device/inode IDs remain strings.

Runner marks fd3 CLOEXEC, verifies pinned private root/state/file identity and the shared held flock, and takes its instance lock. It never explicitly unlocks the inherited open description. No release/reacquire window or general new authority transport.

Before any local marker/schema write, validate external demand at `filepath.Join(filepath.Dir(ownership.Root), "policy-execution-v1", machineWorkspace)`: a sibling of per-workspace executor directories. Valid demands for other workspaces preserve ownership-only behavior for an unenabled current workspace; missing current demand with admission boot refuses. Desk independently verifies full bidirectional registry/demand closure.

Only explicit initial preparation of untouched schema3 may publish schema4. Reject all triggers (even paused), queued/running runs, pending acquisition/occurrences and malformed/unrecognized stores before completing migration.
